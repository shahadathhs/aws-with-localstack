Versioning

Delete markers, restores, noncurrent versions, and why enabling it is a one-way door.

Concept

Without versioning, writing to an existing key overwrites and destroys the previous bytes. With it on, every write adds an immutable version, and a key becomes a stack.

OperationWithoutWith versioning
PUT same keyreplaces bytesadds a version
DELETE keybytes goneadds a delete marker
