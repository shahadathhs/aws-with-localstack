lab · s3 / versioningeu-west-1
predict
PUT, PUT, DELETE on one key with versioning on. How many versions? What does GET return?
my guess: 2 versions, GET returns v2
run
$ aws s3api list-object-versions \
    --bucket ph1-bucket
Versions:      2
DeleteMarkers: 1
$ aws s3 cp s3://ph1-bucket/note.txt -
404 NoSuchKey
verify
Close: 2 versions, but the delete marker is the newest entry, so a plain GET is a 404.
