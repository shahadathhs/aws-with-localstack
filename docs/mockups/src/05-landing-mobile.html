lab · s3 / versioningeu-west-1
predict
PUT, PUT, DELETE on one key with versioning on. How many versions? What does GET return?
my guess: 2 versions, GET returns v2
run
$ aws s3api list-object-versions \
    --bucket ph1-bucket \
    --query '[length(Versions),length(DeleteMarkers)]' \
    --output text
2    1
$ aws s3api get-object --bucket ph1-bucket \
    --key note.txt out.txt
NoSuchKey
verify
Close: 2 versions and 1 delete marker. The marker is the newest entry, so reading the key fails with NoSuchKey.
