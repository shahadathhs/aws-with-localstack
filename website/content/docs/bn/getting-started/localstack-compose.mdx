## রিপো নামিয়ে নাও

এই কোর্সের প্রতিটি কমান্ড চলে রিপোজিটরির একটি ক্লোন থেকে: [shahadathhs/aws-with-localstack](https://github.com/shahadathhs/aws-with-localstack)। এতে আছে compose ফাইল ([`infra/compose.yaml`](https://github.com/shahadathhs/aws-with-localstack/blob/main/infra/compose.yaml)), `make up`-এর পেছনের [`Makefile`](https://github.com/shahadathhs/aws-with-localstack/blob/main/Makefile), সেটিংসের জন্য যে [`.env.example`](https://github.com/shahadathhs/aws-with-localstack/blob/main/.env.example) কপি করবে, আর এই লেসনগুলো।

## অফিসিয়াল উদাহরণ

সরাসরি [অফিসিয়াল ডক](https://docs.localstack.cloud/aws/getting-started/installation/#docker-compose) থেকে:

```yaml
services:
  localstack:
    container_name: '${LOCALSTACK_DOCKER_NAME:-localstack-main}'
    image: localstack/localstack
    ports:
      - '127.0.0.1:4566:4566' # LocalStack Gateway
      - '127.0.0.1:4510-4559:4510-4559' # এক্সটার্নাল সার্ভিস পোর্ট রেঞ্জ
      - '127.0.0.1:443:443' # LocalStack HTTPS Gateway
    environment:
      - LOCALSTACK_AUTH_TOKEN=${LOCALSTACK_AUTH_TOKEN:?} # latest-এর জন্য আবশ্যক
      - DEBUG=${DEBUG:-0}
      - PERSISTENCE=${PERSISTENCE:-0}
    volumes:
      - '${LOCALSTACK_VOLUME_DIR:-./volume}:/var/lib/localstack'
      - '/var/run/docker.sock:/var/run/docker.sock'
```

<Note title="টোকেন আবশ্যক">
  `latest` ইমেজ (2026.x) **LocalStack অ্যাকাউন্ট টোকেন চায়**: `${LOCALSTACK_AUTH_TOKEN:?}` টোকেন ছাড়া `docker compose up` ব্যর্থ করে। টোকেন ছাড়া চালু হলে কন্টেইনার কোড 55 দিয়ে বন্ধ হয় ("License activation failed")।
</Note>

## এই রিপো কী বদলায়, এবং কেন

আমাদের [`compose.yaml`](https://github.com/shahadathhs/aws-with-localstack/blob/main/infra/compose.yaml) (`infra/` ফোল্ডারে) অফিসিয়াল স্ট্রাকচার মেনে চলে, **দুটি পার্থক্য** ছাড়া:

| পার্থক্য                                          | কারণ                                                                                                                  |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `image: localstack/localstack:2026.9.0` (পিন করা) | এই মুহূর্তে `latest`-এর সমান, কিন্তু পিন করা থাকায় পুরো টিম একই ভার্সন পায়। আপগ্রেড মানে ইচ্ছাকৃতভাবে ট্যাগ বাড়ানো |
| `S3_SKIP_SIGNATURE_VALIDATION=${S3_SKIP_SIGNATURE_VALIDATION:-1}` | LocalStack-এর নিজের ডিফল্ট (`1`) presigned URL-এর signature ও expiry যাচাই বাদ দেয়। এটি পাস করে দেওয়ায় `.env`-এ `0` দিয়ে যাচাই চালু করা যায়, যা [presigned URL](/bn/s3/04-presigned-urls/) লেসনে লাগে। |

বাকি সব — টোকেন (`${LOCALSTACK_AUTH_TOKEN:?}`), পোর্ট, `DEBUG`, `PERSISTENCE`, volumes — হুবহু অফিসিয়াল উদাহরণের মতো। আরও **একটি হেলথচেক যোগ** করা আছে, যাতে `make up` (যা `docker compose up -d --wait` চালায়) LocalStack প্রস্তুত না হওয়া পর্যন্ত অপেক্ষা করে।

### টোকেন কীভাবে পাবে

1. [app.localstack.cloud](https://app.localstack.cloud)-এ ফ্রি অ্যাকাউন্ট খোলো
2. Auth token কপি করো (Account → Auth token)
3. `.env`-এ বসাও: `LOCALSTACK_AUTH_TOKEN=ls-...`
4. `make up`

## প্রতিটি সেটিং কী করে

| সেটিং                  | কেন                                                                                                                |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `4566`                 | একক **গেটওয়ে পোর্ট** — প্রতিটি AWS সার্ভিস API এখানেই সার্ভ হয় (S3, SQS, DynamoDB, Lambda... সব এক এন্ডপয়েন্টে) |
| `4510-4559`            | অতিরিক্ত এন্ডপয়েন্ট বাঁধা সার্ভিসের পোর্ট রেঞ্জ (যেমন Elasticsearch)। সাধারণত দরকার হয় না                        |
| `443`                  | HTTPS গেটওয়ে (ঐচ্ছিক — মেশিনে 443 ব্যস্ত থাকলে বাদ দাও)                                                           |
| `127.0.0.1:` প্রিফিক্স | পোর্ট শুধু **localhost-এ** বাঁধে — এমুলেটর নেটওয়ার্কে expose করো না                                                |
| `docker.sock` মাউন্ট   | **Lambda-র জন্য আবশ্যক** — LocalStack ফাংশন চালাতে sibling container চালায়                                        |
| `volume` মাউন্ট        | কন্টেইনারের অভ্যন্তরীণ state (log, cache) — তোমার তৈরি AWS রিসোর্স নয়                                             |

## চালু, যাচাই ও বন্ধ

এগুলো তোমার ক্লোনের রুট থেকে চালাও। [`Makefile`](https://github.com/shahadathhs/aws-with-localstack/blob/main/Makefile) compose কমান্ডগুলো তোমার জন্য মুড়ে রাখে:

```sh
make up        # ব্যাকগ্রাউন্ডে চালু (হেলথচেকের জন্য অপেক্ষা)
docker ps      # STATUS-এ "Up ... (healthy)" দেখা যাবে
make status    # হেলথ চেক: curl localhost:4566/_localstack/health, সুন্দর করে সাজানো
make logs      # LocalStack log ফলো
make down      # বন্ধ
make clean     # বন্ধ এবং সব ডেটা মুছে ফেলা
```

সার্ভিস প্রথম ব্যবহারের আগে `available`, ব্যবহারের পরে `running` দেখায়।

<Destructive title="make clean ডেটা মুছে দেয়">
  `make clean` চালায় `docker compose down -v`, তারপর `volume` ও `.localstack-data` ডিরেক্টরি মুছে দেয়। LocalStack যা কিছু জমিয়েছিল সব চলে যায়।
</Destructive>

compose ফাইল `infra/`-তে থাকায় রিপোর রুট থেকে সাদামাটা `docker compose up` চালালে "no configuration file provided" বলে ব্যর্থ হয়। নিজে raw compose কমান্ড চালাতে চাইলে Makefile যে রূপ ব্যবহার করে সেটাই ব্যবহার করো:

```sh
docker compose --project-directory . -f infra/compose.yaml <command>
# যেমন: up -d --wait | down | logs -f localstack
```

## ট্রাবলশুটিং

- **কন্টেইনার (55) বন্ধ — "License activation failed"** → ইমেজ `latest`/2026.x কিন্তু `LOCALSTACK_AUTH_TOKEN` নেই। `4.9.0` পিন করো বা টোকেন দাও
- **`make up` ব্যর্থ — "LOCALSTACK_AUTH_TOKEN not set"** → অফিসিয়াল `${...:?}` সিনট্যাক্স টোকেন দাবি করছে; এই রিপোর compose ফাইলও এটি ব্যবহার করে, তাই `.env`-এ টোকেন বসাও
- **পোর্ট ব্যস্ত** (4566 বা 443) → ম্যাপিংয়ের বাম পাশ বদলাও, বা `443` লাইন বাদ দাও
- **Lambda চালু হয় না** → `/var/run/docker.sock` মাউন্ট অনুপস্থিত
- **`health: starting`-এ আটকে** → প্রথম বুটে ~১৫ সেকেন্ড দাও; না হলে `make logs` দেখো

<Recap>

- আগে [রিপোজিটরি](https://github.com/shahadathhs/aws-with-localstack) ক্লোন করো: compose ফাইল, `Makefile` আর `.env.example` সবই সেখানে।
- একটি গেটওয়ে পোর্ট (`4566`) সব সার্ভিস সার্ভ করে, শুধু localhost-এ বাঁধা; `docker.sock` মাউন্টই Lambda চালায়।
- `infra/`-র compose ফাইল = অফিসিয়াল উদাহরণ + পিন করা ইমেজ + হেলথচেক, আর `.env`-এ `LOCALSTACK_AUTH_TOKEN` লাগে।
- রিপোর রুট থেকে `make up`, `make status`, `make logs`, `make down`, `make clean` ব্যবহার করো; `make clean` তোমার ডেটা মুছে দেয়।

</Recap>
