## How it works

1. `make up` — start the sandbox: a full AWS emulator in Docker on your machine.
2. `make demo` — make your first real API calls: a bucket, a queue, a table.
3. Follow the lessons: read a concept, _predict_ the behavior, run it, verify.

The gap between your prediction and the actual output is where the learning happens.
