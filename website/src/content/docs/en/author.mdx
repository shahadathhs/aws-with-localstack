**Shahadath Hossen Sajib** is a backend engineer based in Dhaka, Bangladesh. He builds microservices and AI-powered systems with Node.js, TypeScript, NestJS, and Python, and he deploys what he builds — Docker on AWS, CI/CD pipelines, Linux boxes behind Nginx.

He created **AWS with LocalStack** after noticing the biggest barrier to learning AWS was not the concepts — it was the bill. Every lesson on this site follows the same rule he uses at work: understand the service, then prove it with a real API call, even if the API is running on `localhost:4566`.
