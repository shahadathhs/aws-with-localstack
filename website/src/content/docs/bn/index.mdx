## এটি কীভাবে চলে

1. `make up` — স্যান্ডবক্স চালু: তোমার মেশিনে Docker-এ পূর্ণ AWS এমুলেটর।
2. `make demo` — প্রথম আসল API call: একটি bucket, queue, table।
3. লেসন অনুসরণ করো: কনসেপ্ট পড়ো, _আচরণ অনুমান_ করো, চালাও, যাচাই করো।

তোমার অনুমান আর বাস্তব আউটপুটের ফারাকই আসল শিক্ষা।
